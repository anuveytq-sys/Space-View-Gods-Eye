## Overview

**God's Eye View** fuses real-time open signals into a unified 3D operational picture: aircraft ADS-B, AIS vessels, satellites, wildfires, earthquakes, and public CCTV — rendered on a photorealistic CesiumJS globe.

## Quick Start

```bash
cp .env.example .env   # add your API keys
npm install
npm run dev
```

See `.env.example` and `DATA_SOURCES.md` for required keys and data attribution.
